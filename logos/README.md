# CLARRX Logos

This directory contains the official CLARRX logo files used across all digital and print platforms.

## Available Formats

- PNG
- SVG
- PDF
- Transparent PNG
- White Version
- Black Version
- Favicon

## Usage Guidelines

- Use only the official logo files provided in this directory.
- Do not stretch, distort, rotate, or recolor the logo.
- Maintain adequate clear space around the logo.
- Refer to the **Brand Guidelines** for complete usage instructions.
